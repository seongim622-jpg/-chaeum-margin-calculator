개당 매입가, 구매 수량, **총 매입 배송비**, 개당 포장비, 목표 마진율 중심으로 구성한 웹앱입니다.

## 계산 규칙

- 총 매입 금액 = 개당 상품 매입가 × 구매 수량 + 매입 배송비
- 배송비 포함 개당 매입원가 = 개당 상품 매입가 + 총 매입 배송비 ÷ 구매 수량
- 개당 고정 비용 = 배송비 포함 개당 원가 + 포장비 + 판매자 배송비/주문당 수량 + 기타 비용 + 정액 광고비
- 판매수수료, 별도 카드수수료, 정률 광고비, 세금 적립률은 해당 계산 기준에 따라 별도로 적용
- 손익분기 판매가와 목표 마진 판매가는 변동 비용률을 고려한 방정식으로 산출 후 단위 올림
- 실제 부가세 및 소득세는 계산하지 않고 별도 안내
